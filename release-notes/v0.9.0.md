{% raw %}v0.9.0 adds hand-written and GitHub-generated release notes to changelog templates, a `--skip-build` flag for building on parallel CI runners, a fix for archives in parallel builds, and dependency updates for several security advisories.

## What's new

### Hand-written release notes
Changelog templates can now `{% include %}` files, with paths relative to where rlsr runs. Keep a notes file per release and put it above the generated changes:

```jinja
{% include "release-notes/" ~ meta.tag ~ ".md" ignore missing %}
```

Releases without a notes file get only the generated changes. See [Per-release notes](https://rlsr.sarat.dev/templating/#per-release-notes).

### GitHub-generated notes: `github_notes`
With `changelog.format: "github"`, templates can use `github_notes`. It holds GitHub's generated release notes for `previous_tag...tag`: merged PRs with authors and links, **New Contributors** and a **Full Changelog** link. This is the same output as the "Generate release notes" button and goreleaser's `github-native` changelog.

```jinja
{% include "release-notes/" ~ meta.tag ~ ".md" ignore missing %}

{{ github_notes }}
```

Exclusions for these notes go in `.github/release.yml`, not `changelog.exclude`. The API is only called when the template uses `github_notes`.

### `--skip-build`: package binaries built elsewhere
`--skip-build` skips each build's command, `prehook` and `posthook`, then archives, checksums and publishes the files already at the configured `artifact` paths. Build each target on its own CI runner, then run rlsr once to publish them all, with the same `rlsr.yml` you use locally. See [Build on parallel runners](https://rlsr.sarat.dev/github-actions/#build-on-parallel-runners). Buildx builds aren't supported with `--skip-build`.

## Fixes
- Parallel builds that shared a `bin_name` (for example, Linux and macOS binaries both named `rlsr`) could put one build's binary into another build's archive, because both copied it to the same `dist/<bin_name>` path. Archives are now created straight from each build's `artifact`.

## Security
Updated dependencies with published advisories:
- `rustls-webpki` 0.102.5 → 0.103.15 (via `rustls` 0.23.46): CRL parsing panic, name-constraint and CRL distribution point fixes
- `tar` 0.4.44 → 0.4.46: PAX header handling fixes
- `quinn-proto` 0.11.8 → 0.11.19, `lz4_flex` 0.11.5 → 0.11.6, `bytes` 1.6.0 → 1.12.1, `time` 0.3.36 → 0.3.47, `keccak` 0.1.5 → 0.1.6
- `rand` 0.8.5 is no longer in the dependency tree

## Upgrading
No configuration changes are needed. GitHub Actions users can pin `iamd3vil/rlsr/.github/actions/rlsr@v0.9.0`.
